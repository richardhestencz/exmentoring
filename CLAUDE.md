# Exmentoring

Önálló mentoring projekt. NEM része a ~/Brain vaultnak és a side hustle-öknek (Olivia, PTL, bytheloop): azok szabályai, eszközei és naplói itt nem érvényesek, és ide sem kerül semmi onnan.

- Leírás és telepítés: README.md, HANDOVER.md
- Tesztek: `cd server && npm test`
- Helyi futtatás: `cd server && INGEST_TOKEN=valami npm start`
- A repó nyilvános lesz: token, telefonszám, kollégák nevei csak a Mac mini `.env`-jébe.
